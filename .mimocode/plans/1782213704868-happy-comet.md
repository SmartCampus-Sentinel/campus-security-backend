# 剩余功能计划：OpenPose + Redis Token黑名单

## 第1步：OpenPose姿态识别（Python AI服务）

### 目标
在Python AI服务中添加姿态识别能力，检测人员是否佩戴安全帽、反光衣等防护用具。

### 修改文件
- `src/ai/requirements.txt` — 添加 `mediapipe` 依赖（Google的轻量级姿态估计库，比OpenPose更易部署）
- `src/ai/src/config.py` — 添加姿态识别配置
- `src/ai/src/services/pose_service.py` — **新建** 姿态识别服务
- `src/ai/src/models/schemas.py` — 添加姿态识别请求/响应模型
- `src/ai/src/main.py` — 添加 `/pose/detect` 接口

### 实现方案
使用 **MediaPipe Pose** 替代OpenPose（原因：MediaPipe是纯Python安装，无需编译Caffe/PyTorch模型，部署更简单）：
- 检测人体关键点（33个landmark）
- 根据关键点判断是否佩戴安全帽（头部区域检测）
- 根据关键点判断是否穿反光衣（躯干区域检测）

### 接口
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/pose/detect` | 姿态识别检测 |

请求：`{ "image_url": "...", "check_type": "helmet|vest|both" }`
响应：`{ "has_helmet": true/false, "has_vest": true/false, "confidence": 0.95, "keypoints": [...] }`

## 第2步：Redis Token黑名单（Java后端）

### 目标
登出时将JWT token加入Redis黑名单，使token立即失效。

### 修改文件
- `src/main/java/com/smartcampus/security/JwtAuthenticationFilter.java` — 验证token时检查Redis黑名单
- `src/main/java/com/smartcampus/controller/AuthController.java` — 登出时将token加入黑名单
- `src/main/java/com/smartcampus/utils/JwtUtils.java` — 添加获取token过期时间方法

### 实现逻辑
1. 登出：从Authorization header取token → 存入Redis `blacklist:{token}`，TTL=token剩余有效期
2. 验证：JwtAuthenticationFilter在validateToken后额外检查Redis黑名单
3. 命中的token视为无效，返回401
